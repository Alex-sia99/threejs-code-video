# Musiques

- `*.mp3` (sauf `loop-*`) : musique du film, mixée sous les voix par `node scripts/mix.js` (bouclée si plus courte que le film).
- `loop-*.mp3` : musique d'une boucle, coupée à 60 s avec raccord sans couture par `node scripts/loop-mix.js`.

Les mp3 sont ignorés par git. Générez-les avec l'outil de votre choix (Suno, ElevenLabs Music…) et déposez-les ici.
